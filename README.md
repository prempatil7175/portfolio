# MUKESH PATIL — ELECTRICAL & AUTOMATION ENGINEER PORTFOLIO

A modern, high-impact, brutalist dark-mode portfolio for **Mukesh Patil**, Chief Electrical & Automation Engineer with 26 years of heavy-industrial expertise across captive power generation, drive systems, paper machines, and plant-wide digital transformation.

---

## 🎨 Design System & Aesthetic Principles

- **Theme**: Pure Dark Mode
  - Background: Deep Black (`#090909`, `#000000`)
  - Accent: Bold, Aggressive Electric Red (`#E50914`, `#FF1E27`)
  - Typography: Crisp White (`#FFFFFF`) with secondary technical copy in `#A0A0A0`
- **Typography Hierarchy**:
  - Headings: `Oswald` / `Impact` (Oversized, tight tracking, brutalist uppercase)
  - Body: `Inter` / `Roboto` (Optimized legibility)
  - Technical Telemetry / Coordinates: `JetBrains Mono`
- **Styling Details**:
  - Industrial brutalist framing with corner brackets (`[ + ]`)
  - Razor-sharp 1px border dividers
  - Glowing red telemetry status indicators & meters
  - Interactive custom cursor with red reticle expansion
  - Parallax floating titles and scroll reveal micro-interactions

## 🚀 How to Run & View

### Option 1: Direct In-Browser (Instant, Zero Setup)
Simply open `index.html` in your browser (Google Chrome, Microsoft Edge, Safari, or Firefox).

### Option 2: Run with Built-in Server
Run:
```bash
node serve.js
```
Then visit: `http://127.0.0.1:3000`

### Option 3: Modern React + Vite Build
If you have Node.js and npm installed:
```bash
npm install
npm run dev
```
To create an optimized production bundle:
```bash
npm run build
```
